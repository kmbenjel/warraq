## البطاقات

صفحة المراجعة مجموعة بطاقات، في كل بطاقةٍ ما يحتاج إلى قرارك: صورةٌ قبل وبعد، أو اسمٌ مقترح، أو مطابقةٌ مشكوكٌ فيها. يكتبها الوكيل في ملف JSON أو TSV:

```bash
awb page build crops --cards cards.jsonl --title "مراجعة القصّ"
```

## على خادمٍ بعيد

حين تكون الصور كثيرة أو العمل ثقيلًا، تُبنى الصفحة على خادمٍ سحابي، ويعمل خادمها هناك على `127.0.0.1`. وتصل إليه من حاسوبك بنفق SSH، فيبقى العنوان على حاسوبك كما هو:

```bash
awb remote up
```

وتعود تعليقاتك من الخادم البعيد إلى حاسوبك كل بضع ثوانٍ، حتى تُغلق النفق:

```bash
awb remote down
```

## خفّة الصفحة

الصور مصغّرة وتُحمَّل عند الحاجة، فتبقى الصفحة خفيفةً على المتصفح وإن كانت فيها آلاف البطاقات.
