## جرّب العيّنة

```bash
uvx agent-workbench demo --serve
```

يبني هذا الأمر صفحة مراجعةٍ من نصٍّ في الملك العام، ويشغّل الخادم على حاسوبك فقط (`127.0.0.1`). افتح العنوان الذي يطبعه، وأشّر على بطاقة، واكتب تعليقًا.

## اقرأ ملاحظاتك كما يقرؤها الوكيل

في طرفيةٍ أخرى:

```bash
awb watch --from-start
```

يظهر سطرٌ لكل تعليقٍ استقرّ.

## أغلق البطاقة

```bash
awb close demo card-1 "«…نص تعليقك…» صُحّح"
```

لا تُغلق البطاقة إلا بجوابٍ يقتبس تعليقك بين «»، أو يصرّح بأنه اجتهاد، أو يعيد فتحها.

## الحالة

```bash
awb status
```
