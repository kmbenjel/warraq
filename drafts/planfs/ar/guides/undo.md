## اقرأ السجل

```bash
uvx planfs log
```

ترى لكل خطةٍ طُبّقت عدد عملياتها ووقتها، ولكل عمليةٍ مصدرها وهدفها وسببها.

## تراجع عن خطةٍ كاملة

```bash
uvx planfs undo NAME --dry-run
uvx planfs undo NAME
```

يُعاد كل ملفٍّ إلى مكانه واسمه بترتيبٍ معكوس، وتعود الملفات المحذوفة من مجلد الحجر.

## حين تغيّرت الملفات بعد الخطة

إن نُقل ملفٌّ بعد تطبيق الخطة، تكشف المعاينة ذلك، فلا يُكتب ملفٌّ فوق آخر. حلّ التعارض بخطةٍ صغيرةٍ جديدة، ثم أعد التراجع.
